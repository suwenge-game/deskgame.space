How to play

Short answer: Guess the hidden five-letter word in six attempts. Each submitted word must appear in the accepted dictionary.

Read the colors

ColorMeaning
GreenThe letter is correct and in the correct position.
GoldThe letter is in the answer but belongs elsewhere.
GrayThe letter is not available in that position or all copies are already used.

Use the keyboard

Type with a physical keyboard or tap the on-screen keys. Enter submits a complete word. Backspace removes the latest letter. Keyboard colors retain the strongest clue found for each letter.

Repeated letters

Letters are counted. If your guess contains two copies but the answer contains one, only one can be green or gold. The other becomes gray.
